SocialPulse NLQ

Independent synthetic product analytics. Not affiliated with Meta. Ask in plain English; the planner maps your question to a catalog metric, builds SQL from an allowlisted template, checks it with a read-only guard, and returns a receipt.

Product health — weather report

Not one metric and not a score: DAU, WAU, retention, and creator health, last 28 days vs the prior 28 days, with watchouts. Asking "How is the product doing?" below gives you this same report.

Phase 3 chat — multi-turn assistant

Deterministic, no LLM: the chat keeps the app and topic in state, so a follow-up means something. Start with "What's happening with Instagram?", pick a drill-down, then ask for a diagnosis, an experiment recommendation (labelled HYPOTHESIS, never a forecast), or the PM/Eng brief. If a step is wrong, correct it in chat — for example "you are not looking at retention" or "show daily, not average" — and it re-runs that step and prompts the next one. Restarting app.py resets chat history.

Questions editor — chat flow + evals, in one place

Both in one: the Flow tab edits what the chat asks and recommends (labels, diagnosis order, recommendation hypotheses) in chat/questions.json; the Single-shot evals and Conversation evals tabs edit what the chat is graded on in evals/benchmark_phase2.json and evals/conversation_phase3.json. Saves are validated and written to those files only — they never change code or SQL. Edited flow takes effect for a new chat session, not the one already open. Flow and evals are separate tabs on purpose: editing the flow changes what the bot does, editing an eval changes what you expect it to do, and mixing them would let you grade the bot on a question you just taught it. To add a single-shot eval, fill in the question and the expected metric, then run the benchmark and copy the actual value into the gold field if it differs — the benchmark runner, not the editor, is what computes golds.
